# Lernfeld 2 – Aufgaben (Python)

Hier findest du die praktischen Übungsaufgaben zum Modul **Einfache
Datenverarbeitung und Algorithmen**. Bearbeite sie **in Reihenfolge** – der
Schwierigkeitsgrad steigt.

| Aufgabe | Thema | Schwierigkeit |
|---|---|---|
| [Aufgabe 1](aufgabe_01.md) | Zahlenstatistik aus Datei (Datei-I/O, Schleifen) | ⭐⭐ |
| [Aufgabe 2](aufgabe_02.md) | Bubble Sort selbst gebaut (Sortieren) | ⭐⭐ |
| [Aufgabe 3](aufgabe_03.md) | Binäre Suche (Suchalgorithmen, Indexberechnung) | ⭐⭐⭐ |
| [Aufgabe 4](aufgabe_04.md) | Wortfrequenz-Analyse (Dictionaries, Ranking) | ⭐⭐⭐ |
| [Aufgabe 5](aufgabe_05.md) | Laufzeit-Vergleich Python vs. C++ (Performance) | ⭐⭐⭐⭐ |

## So arbeitest du

1. Aufgabenstellung genau lesen und das **Beispiel** (Ein-/Ausgabe) verstehen.
2. Eigenen Code schreiben – z. B. `loesung_01.py` **in deinem eigenen Ordner**.
3. Programm ausführen: `python3 deine_datei.py`
4. Randfälle testen: leere Datei, fehlende Datei, unsortierte Daten, Extremwerte.
5. Haken im Selbsttest jeder Aufgabe setzen – und erst danach weitermachen.

> 💡 **Tipp:** Die Aufgaben bauen aufeinander auf. In Aufgabe 3 nutzt du die
> Schleifen-Logik aus Aufgabe 2, in Aufgabe 5 die binäre Suche aus Aufgabe 3 –
> und Aufgabe 1 und 4 lesen beide Dateien ein. Überspringen lohnt sich nicht.

## Allgemeine Hinweise

- Nur die Python-Standardbibliothek – keine `pip install`-Pakete nötig.
- Die Beispieldateien (`zahlen.txt`, `text.txt`) legst du selbst an – z. B. mit
  `nano zahlen.txt` im Terminal.
- Schreibe lesbaren Code: aussagekräftige Namen, kleine Funktionen, Kommentare.
- Jede Aufgabe hat eine **Erweiterung (Bonus)** – mach sie, wenn die Basis steht.
- Die Musterlösungen erscheinen nach und nach in `../loesungen/` – erst
  anschauen, wenn deine eigene Lösung steht!
