## Themen dieses Moduls

- **Unit-Testing**: pytest (Python) und doctest/Catch2 (C++)
- **Debugging**: Debugger, Stacktraces, systematische Fehlersuche
- **Refactoring** und Clean Code: Lesbarkeit, Namensgebung, kleine Funktionen
- **Code-Review**: fremden Code lesen und konstruktiv kritisieren
- **Git & GitHub** im Team: Branches, Pull Requests, Konflikte lösen
- **CI/CD**: automatische Tests bei jedem Push (z. B. GitHub Actions)
- **Projektmanagement**: Agile/Scrum, Issues, Schätzungen, Dokumentation

## Geplante Aufgaben (Auswahl)

1. Bestehende Lösungen aus Lernfeld 1 mit Tests absichern
2. Test-first: Aufgabe formulieren, Tests schreiben, dann Code (TDD)
3. Bewusst fehlerhaften Code debuggen (vorgegebene Bugs finden)
4. Refactoring: unlesbaren Code Schritt für Schritt verbessern
5. Code-Review einer fremden Lösung (z. B. aus der Community)
6. CI-Pipeline für dieses Repository aufsetzen (GitHub Actions)
