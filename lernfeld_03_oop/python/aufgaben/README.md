# Lernfeld 3 – Aufgaben (Python)

Hier findest du die praktischen Übungsaufgaben zum Modul **Objektorientierte
Programmierung**. Bearbeite sie **in Reihenfolge** – der Schwierigkeitsgrad
steigt.

| Aufgabe | Thema | Schwierigkeit |
|---|---|---|
| [Aufgabe 1](aufgabe_01.md) | Bankkonto (Klassen, Attribute, Methoden, Validierung) | ⭐ |
| [Aufgabe 2](aufgabe_02.md) | Vererbung: `Fahrzeug` → `Auto`, `Fahrrad` | ⭐⭐ |
| [Aufgabe 3](aufgabe_03.md) | Polymorphie: `Tier` → `Hund`, `Katze` (`gib_laut()`) | ⭐⭐ |
| [Aufgabe 4](aufgabe_04.md) | Bibliothekssystem (Klassen-Projekt: `Buch`, `Bibliothek`) | ⭐⭐⭐ |
| [Aufgabe 5](aufgabe_05.md) | Objekt-Lebenszeiten (`__init__`/`__del__`, Dunder-Methoden) | ⭐⭐⭐ |

## So arbeitest du

1. Aufgabenstellung genau lesen und das **Beispiel** (Ein-/Ausgabe) verstehen.
2. Eigenen Code schreiben – z. B. `loesung_01.py` **in deinem eigenen Ordner**
   (nicht in `loesungen/` reinschreiben).
3. Programm ausführen: `python3 deine_datei.py`
4. Randfälle testen: negative Beträge, Überziehung, leere Suche, mehrere
   Objekte, `print()` auf jedes Objekt.
5. Die **Erweiterung (Bonus)** machen, wenn die Basis steht.

> 💡 **Tipp:** Skizziere bei OOP-Aufgaben zuerst das Klassendiagramm auf
> Papier (Klasse = Kasten, Attribute oben, Methoden unten, Vererbung = Pfeil).
> Wer erst denkt und dann tippt, ist bei Klassen doppelt so schnell.

## Allgemeine Hinweise

- Nur die Python-Standardbibliothek – keine `pip install`-Pakete nötig.
- Schreibe lesbaren Code: aussagekräftige Namen, kleine Methoden, Kommentare.
- Jede Aufgabe hat eine **Erweiterung (Bonus)** – mach sie, wenn die Basis steht.
- Das [Modul-README](../README.md) gibt dir den Überblick über alle Teile des
  Lernfelds – und nach jeder Aufgabe wartet die C++-Version auf dich.
